# Workspace Guidelines

## Changelog Policy
You must automatically update the `assets/changelog.html` file after every significant code edit or feature modification. 
*   **Behavior**: When you make changes to HTML, CSS, or JS files, make it a standard practice to append a new entry to the top of `assets/changelog.html`.
*   **Format**: Follow the existing HTML structure (`changelog-item`, `changelog-entry`, `changelog-badge-group`, `changelog-list`) and use the correct Material Symbols icon.
*   **Versioning**: Increment the patch or minor version number appropriately based on the scope of the change.
